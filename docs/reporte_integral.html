🚀 Fase 6: Deployment & Conclusiones

🎯 Conclusiones

  1. Desbalanceo significativo: Solo 14.96% de reservas completadas. SMOTE fue esencial.
  2. Mejor modelo: Random Forest + SMOTE (AUC-ROC: 0.785). Buena capacidad discriminativa.
  3. Factor clave: purchase_lead es el predictor mas importante (18.2% de importancia relativa).
  4. Servicios adicionales: Clientes que solicitan equipaje extra, asiento preferencial o comidas completan mas.
  5. Canal Mobile: Menor tasa de conversion vs Internet. Oportunidad de mejora UX.

💡 Recomendaciones de Negocio

  1. Retargeting inteligente: Campanas para clientes con probabilidad >30% de completar.
  2. UX Mobile: Mejorar experiencia en canal movil para aumentar conversion.
  3. Incentivos: Ofrecer equipaje extra o asiento preferencial como incentivo.
  4. Alertas tempranas: Notificar a clientes con largo purchase_lead para evitar abandono.
  5. Modelo en produccion: Desplegar Random Forest como API para predicciones en tiempo real.
